# build / routing
- When all routes under a subtree 404 (e.g., every /dashboard/admin/... and /dashboard/customer/... page) while the page files, layouts, and imports all exist, the root cause is a stale/corrupted `.next` dev build cache (partial route manifest + malformed generated types): fix by deleting `.next` and restarting the dev server to regenerate the manifest, then verifying each route returns 200 (e.g., curl per route). Confidence: 0.65
